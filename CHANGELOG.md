# Changelog — platform-2-core

## P2-0005 — проекты, дерево локаций, единицы измерения; меню План/Факта (ветка `task/P2-0005-projects-locations`, ждёт приёмки)

- Миграция `006` (применена 21.10.2026; из-за кодировки буфера пришлось доприменить `006a_fix_encoding.sql` и повторить `006_up`): `projects.code/archived_at`, `planfact.locations` (дерево до 6 уровней, мягкое удаление), `planfact.units` (9 общих + свои), действия `planfact.projects.manage` и `planfact.units.manage` (выданы админу, РП, ПТО, в том числе уже созданным ролям), функции `pf_*`, генератор корпуса (≤ 5 000 узлов, одна транзакция), журнал компании показывает проекты/локации/единицы.
- «План/Факт»: подвкладки в боковом меню (`manifest.nav` → нижний таббар и nav2 оболочки через `window.RBI.platformNav`): «Работы», «Справочники» (→ «Объекты»: проекты и структура; «Единицы»). Видимость «Справочников» — по доступу пользователя к компании, сервер проверяет всё.
- «Компания» (роли, сотрудники, журнал) перенесена в «Настройки → Компания» (`#/settings/company`); из бокового меню убрана.
- Исправлено: переход через роутер оболочки (`history.pushState`) не вызывал `hashchange` → модуль шлёт `planfact:route`; выравнивание заголовков числовых колонок таблицы; вкладки «Компании» в стиле «Настроек»; форма «Сотрудники» (flex-direction).
- Тесты: `006_projects_locations.sql` (91, локально PGlite), `test:server` 86 PASS, unit 103. `sw.js`: кэш 18.59.66.

## P2-0004b — конструктор ролей: «Компания → Роли / Сотрудники / Журнал» (ветка `task/P2-0004b-role-builder`, ждёт приёмки)

- Миграция `005` (применена 21.10.2026): функции экранов ролей и сотрудников, правила защиты на сервере (шаблоны только копируются, без самоназначения, «последний администратор», назначенную роль не удалить, неизвестное действие/чужая компания — отказ), журнал изменений ролей и назначений, прямой SELECT `audit_log` закрыт, журнал проекта — только работы. Решение владельца: администратор может отметить любое действие каталога.
- Новый раздел платформы «Компания» (`src/platform/company/`, бандл `js/dist/company/company.js`): пункт меню только при `security.roles.assign` (флаг `menu.requiresAccess` + `RBI.platformMenuAccess`).
- Форма входа вынесена в платформу (`src/platform/auth/LoginForm.ts`), один клиент Auth на страницу; «План/Факт» и «Работать локально» без изменений.
- Тесты: `005_role_builder.sql` (48), `test:server` 55 (+24), unit 74 (+21). `sw.js`: кэш 18.59.61.

## P2-0004 — вход, компании, роли и права на сервере (ветка `task/P2-0004-access-rls`, ждёт приёмки)

- Сервер (общий Supabase, ADR-061): схема `planfact` — компании, проекты, участники, работы, каталог действий (19), 9 ролей-шаблонов, роли компании, назначения «пользователь → роль → проект» со сроком/отзывом, модули компании, журнал аудита (append-only). RLS на всех таблицах; одна функция проверки права `planfact.has_permission`. Миграции `supabase/migrations/001–004` (up/down).
- Доступ приложения — только через `public.pf_*` (схема `planfact` не открыта в PostgREST; настройки сервера не менялись).
- Вход почта + пароль (`src/platform/auth/auth.service.ts`, `@supabase/supabase-js` 2.118.0), форма входа, выход, шапка «почта · компания · роль»; «Работать локально (демо)» сохранён. Ключи `P2_SUPABASE_URL/ANON_KEY` в `config.service.js`; старые `SUPABASE_URL/KEY` пусты.
- «План/Факт» из базы: переключатель проекта, «Добавить работу» (по праву `planfact.works.edit`), колонка суммы (по `planfact.money.view`), журнал изменений (по `planfact.audit.view`).
- Тесты: `npm run test:server` (REST), SQL-тесты `tests/server/002_permissions.sql`, `004_audit_money.sql`; unit — вход и экран работ (всего 53). `sw.js`: кэш 18.59.60.
- `docs/SERVERS.md` переписан: что создано, как применять/откатывать, тестовые данные.

## P2-0002 — оболочка + модуль «План/Факт» на демо-данных (ветка `task/P2-0002-shell-planfact`, ждёт приёмки)

- Оболочка отрезана от боевого сервера: пустой `config.service.js` (единственное место настройки), `report.html` берёт конфиг оттуда; облачный вход → «Облачный вход отключён в dev-сборке».
- Service worker: кэш `platform2-v…`, удаляет только свои кэши, API пропускается по пути (без привязки к хосту). IndexedDB `PLATFORM2_DB`.
- Модуль `planfact` (React 19.3.1 + TS): демо-таблица работ (ед., план, факт, %), темы оболочки через CSS-переменные; контракт `init/mount/unmount`; выключатель `enabled` в manifest.
- Общий пункт меню модулей Platform 2.0 (`getPlatformMenuItems()` в `app-shell.js`).
- Скрипты: `npm run dev`, `npm test`, `npm run build:planfact`; удалён `check:boundaries` (нет `_ai/scripts`).
- Регламент разработки перенесён в репозиторий (`CLAUDE.md`, `AGENTS.md`, `FILE_MAP.md`, `README_START_HERE.md`, `ai-dev/`).
- `docs/SERVERS.md` — старый адрес сервера и порядок подключения (после P2-0004).
