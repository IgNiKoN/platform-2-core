## Ошибка после выкладки: «Обновить → бесконечная загрузка» на телефонах со старым приложением (26.10.2026)

- Симптом (владелец): старое приложение показывает «Доступно обновление» → после нажатия бесконечная загрузка; установка с нуля работает.
- Причина (воспроизведено локально: старое приложение `c6f6b02` → подмена файлов на выпуск): `sw.js` отвечал `caches.match(request)` — поиск во **всех** кэшах, первым в кэше старого приложения `rbi-quality-v18.59.59` (263 файла с теми же путями) → страница получала старые `index.html`/`bootstrap.js` вперемешку с новыми (сверка: `caches.match` отдал старый `bootstrap.js` 20 165 байт при новом 18 513 в своём кэше). Вторая часть: чистка страницы (`legacy-device.ts`) удаляла `rbi-quality-*` раньше, чем новый `sw.js` проверял его наличие, → новая версия ждала кнопку, старый `sw.js` оставался главным.
- Исправление (SW 18.86.1 → 18.86.2, коммиты `c049867`, `1887213`): ответ — только из своего кэша (`caches.open(CACHE_NAME).match`); при установке поверх старого приложения (кэш `rbi-quality-*` есть в начале или в конце установки) — `skipWaiting` без кнопки; при включении — удаление `rbi-quality-*`, `clients.claim`, перезагрузка открытых окон один раз; страница кэши больше не трогает (только базу `RBI_QUALITY_DB` и ключи синхронизации).
- Тесты: `sw-legacy.test.ts` (5: свой кэш; сеть, а не старый кэш; поверх старого — сразу + удаление + перезагрузка окон; кэш пропал во время скачивания; обычное обновление ждёт кнопку), `config.test.ts` обновлён (правило «rbi-quality-* не трогать» из P2-0016 заменено картой P2-0032).
