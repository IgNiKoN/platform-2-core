## 1. Цель

Владелец открывает платформу и видит порядок: в списках объектов нет сотен «REST-…» от автопроверок, выбранная вкладка и подвкладка всегда подсвечены и переключаются с первого раза (меню слева, подвкладки «План/Факт», «Справочники», «Настройки», нижняя панель телефона, кнопка «назад»), а модуль «План/Факт» можно выключить и включить в «Настройках», как другие модули.

## 2. Подтверждённое исходное состояние (22.10.2026, только чтение)

Подтверждённые загрузки ВОР, факт, акты КС-2 защищены от удаления сторожами (триггеры 007/009/010) — простое удаление невозможно.

Серверный флаг `planfact.company_modules.enabled` есть (002), экрана нет.

## 3. Объём реализации

1. **Уборка тестового мусора (CRITICAL — данные общего сервера):** SQL-скрипт `scripts/cleanup-test-projects.sql` (выполняет владелец или Исполнитель по разрешению на шаг): удаляет **только** архивные проекты с именами `REST-%` **только** в компаниях `is_test = true` вместе с их данными (ВОР, связки, факт, КС-2, сметы/КП, журнал этих проектов) — сторожа отключаются только внутри транзакции скрипта для этих строк; до удаления — отчёт «сколько и чего будет удалено», после — счётчики. `rest.test.mjs` больше не плодит проекты: один постоянный тестовый объект на компанию (создаётся, если нет; повторно используется; данные прогона помечены и не влияют на проверки) — или иной способ без роста списка, по выбору Исполнителя с обоснованием.
2. **Архив скрыт по умолчанию** во всех списках выбора объекта и в «Справочники → Объекты»; переключатель «Показать архив».
3. **Вкладки и подвкладки:** матрица переходов (меню слева, подвкладки «План/Факт» — Сводка / ВОР / Факт / Смета / КС-2 / Справочники, подвкладки «Справочники», «Настройки → Компания», нижняя панель телефона) × способ (клик, прямой адрес, обновление страницы, назад / вперёд, переход по ссылке изнутри, например «Требует внимания» → КС-2): подсвечено ровно то, что открыто; переключение с первого нажатия; единый источник «что открыто» — маршрут оболочки (`#/раздел/:subTab`), без второго состояния в модуле.
4. **Отключение модуля «План/Факт» в «Настройках»** тем же механизмом и экраном, что у Quality / Construction / Knowledge (`enabledModules`): выключен — пункт меню и подвкладки скрыты, прямой адрес `#/planfact…` открывает понятную подсказку «Модуль выключен в настройках»; включить обратно — всё на месте. «Компания» (роли, участники) не выключается.

**Вне блока:** серверная подписка компании на модуль (`company_modules`, по компании, а не по устройству) — с переездом на свой сервер / по спросу; ВОР с подпозициями (P2-0012); один вход (P2-0013); переписывание оболочки.
